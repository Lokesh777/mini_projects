Build a Todo Application using React.

Requirements:

* Add a new todo
* Mark a todo as completed/uncompleted
* Edit an existing todo
* Delete a todo
* Add filters for:

  * All
  * Active
  * Completed

Technical Expectations:

* Use functional components and React hooks
* Manage state efficiently (preferably using `useReducer`)
* Follow immutable state update patterns
* Keep the UI responsive and clean
* Write reusable and maintainable code

Bonus:

* Persist todos in localStorage
* Add basic validations and keyboard support
